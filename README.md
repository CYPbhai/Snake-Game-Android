# Snake-Game-Android
Classic Snake game built in Unity C# for  Android with touch controls and progressive difficulty scaling. It's an android game developed using Unity game engine following "Introduction To Game Development by South-Eastern Finland University of Applied Sciences, XAMK" online course.
